# ServerMaster 多服务器批量管理工具

在一个程序窗口里同时观看多台 Windows Server 的实时桌面、对单台/多台同步键鼠操作、批量分发文件。

> 完整设计（可行性论证 / 架构 / 关键技术 / 风险 / 路线图）见 **[docs/设计文档.md](docs/设计文档.md)**

## 功能

| 功能 | 说明 |
|------|------|
| 多画面同屏 | 每台服务器一个独立 RDP 会话分格实时画面，自动近方阵布局（或固定 1~4 列），双击标题单画面放大 |
| 单画面操作 | 点击任意分格即像本机一样操作该服务器 |
| 输入广播（同步器） | 主控分格正常操作，勾选"广播"的分格同步接收键盘（RDP 官方 SendKeys 扫描码注入）与鼠标（坐标线性换算镜像投递）——一个窗口操作，其他窗口同位置同步执行 |
| 批量文件传输 | ① 拖放直传：文件拖到分格上直接完整传输(SMB)到服务器目标目录（默认 C:\Users\Public\Desktop，可在 工具→设置拖放上传目录 修改；失败自动降级为剪贴板方式）② 批量分发：工具→文件传输，勾选多台服务器上传相同路径 ③ RDP 剪贴板：一键推送后远端 Ctrl+V ④ 可选本地磁盘重定向 |
| 服务器管理 | 分组、搜索、勾选批量连接/断开、控制台会话、色彩深度、自动重连（5 次）；**批量删除：勾选分组或单台 → 点「删除勾选」**；分组右键「删除该组服务器…」；「全部删除」清空清单；**拖拽服务器到其他分组**；分组右键「重命名分组…」 |
| FinalShell 导入 | 工具 → 从 FinalShell 导入：支持导出的 .json 文件或 conn 数据目录；分组自动还原（读各级 folder.json）；兼容新旧两代存储密码算法，本机解密后转 DPAPI 加密；自动去重（与现有清单 + 批内重复）；解密失败的条目标记"需手动录入" |
| 安全 | 密码 DPAPI（当前用户）加密存储；RDP 启用 NLA；SMB 凭据用完即断 |

## 运行要求

- 管理机：Windows 10 / Server 2016 及以上（.NET Framework 4.8 系统自带，**无需安装任何运行时**）
- 服务器：开启远程桌面（3389）；文件传输 SMB 通道需开放 445 且管理员账号可用（默认管理共享 C$）
- 注意：每台 Windows Server 默认允许 2 个并发管理 RDP 会话；本工具设计为"一服务器一路"，多服务器无限制

## 构建

三种方式任选其一：

```bat
:: 方式一：离线构建（零依赖，用 Windows 自带编译器）
build.cmd

:: 方式二：Visual Studio 2022
::   打开 ServerMaster.sln → 生成

:: 方式三：dotnet SDK
dotnet build src\ServerMaster\ServerMaster.csproj
```

产物：`build\ServerMaster.exe`（需与 `AxMSTSCLib.dll`、`MSTSCLib.dll` 同目录，构建脚本会自动复制）。

`lib\` 下的两个互操作程序集由 `AxImp.exe` 从系统 `C:\Windows\System32\mstscax.dll` 生成，
如需在其他开发机重新生成：

```bat
"C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8.1 Tools\AxImp.exe" C:\Windows\System32\mstscax.dll
```

## 使用

1. 启动 → 左侧"＋添加服务器"录入主机/IP、账号、密码（DPAPI 加密落盘）。
   主机栏支持直接填 `主机:端口`（如 `zzw1.example.com:22381`），保存时自动拆分到端口栏
   ；已有 FinalShell 清单可用 工具→从 FinalShell 导入（支持导出文件或 `%APPDATA%\finalshell\conn` 目录）
2. 勾选若干台 → 工具栏"▶全部连接" → 自动分格显示各服务器实时桌面。
   **远端桌面分辨率固定不变**（工具→设置默认远端分辨率，默认 1920×1080；单台可在编辑对话框的"远端分辨率"里覆盖），分格里只是显示端等比缩放——连接/断开/布局变化都不会改动服务器上的桌面分辨率，正在运行的程序窗口不受影响
3. 单台操作：直接点击对应分格
4. **输入同步（广播）**：① 勾选要同步的分格标题栏「广播」复选框 ② 打开工具栏「🔴广播输入」③ 点击某个分格成为主控（标题栏变蓝）——在其中正常键鼠，所有勾选分格同位置同步执行
   （典型用法：勾选 3 台 → 开广播 → 主控输入 `notepad`+回车，3 台同时打开记事本）
5. 文件分发：文件直接拖到目标分格 = 完整传输到服务器目录；多台批量 = 工具栏"📦文件传输"；远端快捷取文件 = 传输窗口的"推送到剪贴板"+远端 Ctrl+V
6. 批量删除：勾选分组复选框（联动组内全部）或单台 → 点「删除勾选」；「全部删除」清空整个清单

## 已知限制

- 广播鼠标为坐标镜像近似实现：普通程序窗口同步良好；使用原始输入（DirectInput/RawInput）的游戏程序可能不响应广播鼠标，此类程序请单独点击该分格操作；扩展键（Win/AltGr）的广播为实验特性
- 中文输入法无法直接广播（广播的是按键扫描码），可先在本地输入后用广播 Ctrl+V 粘贴到多台
- 密码密文仅本机本 Windows 账户可解（导出配置到其他机器需重录密码）
- 需真实服务器环境联调：远程桌面开启、防火墙放行 3389/445
