# 03 · 基础设施：环境探测与互操作

> 《从零写一个多服务器 RDP 批量管理工具》第 3 篇。[系列目录](00-系列总览.md)

写第一行业务代码之前，先要搞清楚"我能在什么环境里构建"。这一步的探测结果直接决定了后面的技术路线，而且发现了好几个只有动手才知道的坑。

## 环境探测：残酷的现实

预期是 dotnet SDK + Visual Studio，实际探测结果：

```
dotnet --list-sdks        → 空（没有 SDK！）
dotnet --list-runtimes    → 只有 .NET 5 运行时
csc.exe                   → C:\Windows\Microsoft.NET\Framework64\v4.0.30319 ✓
AxImp.exe / TlbImp.exe    → .NET Framework 4.8.1 Tools 里有 ✓
```

没有 SDK，但 **Windows 自带的 .NET Framework C# 编译器（csc）还在**。于是技术决策落定：

- 目标框架 .NET Framework 4.8（目标机系统自带运行时，零部署）
- 用 csc 直接编译，配合响应文件（.rsp）管理源文件列表
- 顺带写了个 `build.cmd`，让任何一台 Win10 机器都能离线构建

> 教训在这一步还埋了一颗雷：build.cmd 后来因为一行中文注释整个静默失效，那是 07 篇的故事。

## AxImp：从系统 DLL 生成 RDP 互操作程序集

RDP 客户端控件就在系统里，用 SDK 自带的 AxImp 一条命令生成互操作程序集：

```bat
"C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8.1 Tools\AxImp.exe" C:\Windows\System32\mstscax.dll
```

产出两个文件：

- `AxMSTSCLib.dll` —— AxHost 控件封装（`AxMsRdpClient9NotSafeForScripting` 等）
- `MSTSCLib.dll` —— COM 接口定义（`IMsRdpClientAdvancedSettings*`、`IMsRdpClientNonScriptable`）

## 用反射代替文档：一个真实的坑

生成的互操作程序集里到底有哪些类型、属性签名长什么样？我**没有去翻 MSDN，而是用 PowerShell 反射直接看**：

```powershell
$ax = [Reflection.Assembly]::LoadFrom('AxMSTSCLib.dll')
$ax.GetTypes() | Where-Object { $_.Name -like 'AxMsRdpClient9*' }
$t9 = $ax.GetType('AxMSTSCLib.AxMsRdpClient9NotSafeForScripting')
$t9.GetProperties() | ForEach-Object { $_.Name + ' : ' + $_.PropertyType.Name }
```

这一步立刻值回票价——发现了文档不会告诉你的事实：

1. 事件参数类**不带 `EventArgs` 后缀**：是 `IMsTscAxEvents_OnDisconnectedEvent`，字段是公开的 `discReason`
2. `AdvancedSettings5` 属性返回的接口类型是 `IMsRdpClientAdvancedSettings4`（版本错位是历史遗留）
3. 控件最高支持到 `AxMsRdpClient12`，但 9 就够用且兼容性最好

后来第一次编译就因为事件参数类名报了三个错——如果按文档写，这个坑要花更久。

## 验证控件可实例化

在写任何业务代码之前，先验证技术核心成立——STA 线程里实例化 ActiveX 控件：

```powershell
powershell -STA -Command "
  $ax = New-Object AxMSTSCLib.AxMsRdpClient9NotSafeForScripting
  $form.Controls.Add($ax); $form.Show(); DoEvents
  Write-Host $ax.IsHandleCreated"     # → True ✓
```

控件能创建、句柄能生成，多画面的地基就打好了。

## 基础服务三件套

**DPAPI 密码加密**（P/Invoke crypt32.dll，CurrentUser 作用域 + 应用熵）：

```csharp
public static string Protect(string plain)
{
    byte[] protectedBytes = ProtectBytes(Encoding.UTF8.GetBytes(plain), _entropy);
    return Convert.ToBase64String(protectedBytes);
}
```

**配置原子写**（临时文件 + 替换，避免写一半断电损坏配置）：

```csharp
File.WriteAllText(tmp, json);
if (File.Exists(ConfigFile)) File.Delete(ConfigFile);
File.Move(tmp, ConfigFile);
```

**文件日志**（`%LOCALAPPDATA%\ServerMaster\logs\yyyy-MM-dd.log`），后面所有排错都靠它。

## 本篇要点

- 环境探测决定技术路线：没有 SDK 不代表不能构建，Windows 自带编译器就是后路
- **用反射读互操作程序集，比读文档可靠**——类型名、字段名的历史遗留问题只有反射能提前暴露
- 技术核心（ActiveX 可多实例）先用 5 行脚本验证，再投入业务开发
