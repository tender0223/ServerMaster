# 《从零写一个多服务器 RDP 批量管理工具》系列总览

> 本文是系列索引。全部代码已在 GitHub 开源（MIT 协议，允许二创）。

## 这个工具是做什么的

管理几十台 Windows 云服务器时，我需要的不是一个远程桌面客户端，而是一个"驾驶舱"：

- **多画面同屏**：一个窗口里同时看到 N 台服务器的实时桌面（游戏挂机、程序运行状态一目了然）
- **输入同步（广播）**：在一台服务器上的键鼠操作，同步复现到其他选中的服务器
- **文件直达**：把部署包/脚本一键推到多台服务器的指定目录
- **存量迁移**：把 FinalShell 里积累的连接清单（含密码、分组）一键导入

最终成品 100% 基于 Windows 自带组件，**绿色免安装**，Win10/Server 2016+ 双击即用。

## 技术栈一句话

C# (WinForms) + 微软官方 RDP ActiveX 控件（mstscax.dll）+ SMB 管理共享 + DPAPI 密码加密，.NET Framework 4.8，离线可编译。

## 系列里最有价值的几段

- **05 篇**：`值不在预期的范围内` 这个 COM 错误的完整排查过程——当你从错误消息里得不到任何信息时怎么办
- **06 篇**：FinalShell 两代密码算法的逆向与 C# 复刻（含 `java.util.Random` 的 48 位 LCG 等价实现），以及"解密素材恰好就在用户自己磁盘上"的戏剧性转折
- **07 篇**：一个重要的架构教训——**RDP 的"显示缩放"和"会话分辨率"是两件事**，混淆它们会把用户正在运行的程序窗口全部挤乱
- **03/07 篇**：cmd 批处理的 GBK 解析坑——一行中文注释让整个构建脚本静默失效

## 适用读者

- 想在 WinForms 里内嵌 RDP ActiveX 的开发者
